## 交叉干扰测试

- 问“住宿上限是多少？”：应该追问城市和职级，或展示不同条件，而不是只给单一数字。
- 问“多久审批？”：应区分采购、报销、合同等不同流程。
- 问“什么状态可搜索？”：应只命中 Nebula 文档生命周期内容。

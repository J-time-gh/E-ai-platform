# Nebula 知识库产品说明

## 1. 产品定位
Nebula 是面向内部知识管理的检索服务，支持文档上传、异步解析、向量检索、关键词检索与混合检索。

## 2. 文档生命周期
上传成功后文档状态为 pending；后台任务开始处理后状态为 processing；解析、分块和向量化全部完成后状态为 ready；无法提取文本或处理出现可预期错误时状态为 failed。

## 3. 检索边界
只有状态为 ready 的文档可以被检索。pending、processing 和 failed 文档不会出现在搜索结果中。系统按用户隔离知识库，用户不能检索其他用户上传的资料。

## 4. 文件限制
支持 PDF、DOCX、DOC、TXT、Markdown 和 XLSX 文件，单个文件不超过 20MB。扫描件 PDF 如果没有可提取文本，可能进入 failed 状态。

## 5. 测试要点
- 问：什么状态的文档能被检索？答：ready。
- 问：单文件最大多大？答：20MB。
- 问：扫描 PDF 没有文本会怎样？答：可能处理失败。
